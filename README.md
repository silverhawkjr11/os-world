# OS World

An interactive, voiced 3D walkthrough of an Operating Systems course (OSTEP: virtualization, concurrency, persistence) — 30 scenes.

**Open it:** https://silverhawkjr11.github.io/os-world/

Single self-contained HTML file (three.js + embedded voice-over), works offline too: download `index.html` and open it in a browser.
Each scene opens with a short primer (the problem → what it IS → its features) before the example.
Controls: ☰ Scenes menu · Step / Play · ⟲ Redo (R) · ◀ Back (←) · M mutes voice.
